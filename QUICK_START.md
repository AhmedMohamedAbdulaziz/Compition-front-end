# 🚀 Quick Start Guide

## Instant Setup (Choose One)

### Option 1: Super Simple
1. **Double-click** `index.html` 
2. Website opens in your browser ✅

### Option 2: Use Installation Script

**Windows Users:**
```cmd
install.bat
```

**Mac/Linux Users:**
```bash
chmod +x install.sh
./install.sh
```

### Option 3: Manual Server Setup

**Python (Most Common):**
```bash
python -m http.server 8000
# Open: http://localhost:8000
```

**Node.js:**
```bash
npm install -g live-server
live-server
```

**PHP:**
```bash
php -S localhost:8000
```

## 📁 Files You Get

- `index.html` - Your complete website
- `README.md` - Detailed documentation  
- `install.sh` - Linux/Mac installation script
- `install.bat` - Windows installation script
- `QUICK_START.md` - This file

## 🎨 Customize Your Website

1. **Company Name**: Search & replace "Veented Construction"
2. **Contact Info**: Update phone, email, address in contact section
3. **Colors**: Modify CSS variables in `<style>` section
4. **Images**: Replace placeholder image divs with actual photos
5. **Content**: Edit services, testimonials, about section

## 🌐 Go Live

**Free Options:**
- **GitHub Pages**: Upload to GitHub repo, enable Pages
- **Netlify**: Drag & drop your folder to netlify.com
- **Vercel**: Import project to vercel.com

**Paid Hosting:**
- Upload `index.html` to any web hosting provider

## ⚡ That's It!

Your professional construction website is ready to use. No complicated setup, no dependencies, just open and go!
